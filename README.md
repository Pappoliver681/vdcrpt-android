# vdcrpt-android

Unofficial Android port of vdcrpt.

This project brings vdcrpt to Android while keeping the original corruption effects and a similar UI.

Original project: https://github.com/branchpanic/vdcrpt

This is an unofficial port and is not affiliated with or endorsed by the original author.
